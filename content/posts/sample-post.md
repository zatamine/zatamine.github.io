## Features Demonstrated

### Dark Mode Support

The theme supports both light and dark modes with automatic preference detection. You can toggle between them using the sun/moon icon in the header.

### Responsive Design

The theme is fully responsive, adapting to different screen sizes:
- Mobile: Collapsible navigation menu
- Tablet: Optimized layout
- Desktop: Full-width content

This post includes reading time estimation that automatically calculates based on your content.
